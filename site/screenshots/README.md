# screenshots — real app screenshots

These are **real captures** of the Adhkar desktop app, shown in the
#shots gallery of `site/index.html`. They are WebP (quality 92) so the
page stays fast — re-export from the original PNG at the same settings
if you replace them.

Current files (1600×1067, ~100 KB each):

- `settings-tab.webp` — the Adhkar tab (list, interval, font sizes)
- `capsule-adhan.webp` — adhan-time notice on the desktop
- `capsule-stacked.webp` — dhikr with the countdown below it
- `capsule-side.webp` — dhikr and time side by side

To add or replace one: drop the `.webp` file here and update the
`<img src>` in `site/index.html` (and the caption string in `site/app.js`).

**Important:** never publish a screenshot containing a private file path,
your sound-file name, or your exact coordinates. Take a clean capture
first (no sound file selected, location set to manual).

Video: `site/assets/demo.mp4` (+ `demo-poster.jpg`) is already embedded
in the #demo section. To replace it, overwrite those two files.
